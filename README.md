# 🚀 Telegram WEB Proxy Auto-Installer

Автоматический скрипт для быстрого развертывания официального [Telegram WEB Proxy (tproxy-server)](https://github.com/telegramdesktop/tproxy-server). 

Скрипт делает установку максимально простой: сам генерирует безопасные ключи, настраивает веб-сервер Caddy, получает SSL-сертификат и выдаёт готовую кликабельную ссылку для подключения в Telegram.

## ✨ Особенности
- **Полная автоматизация**: минимум вопросов, всё настраивается под капотом.
- **Генерация ключей**: автоматическое создание правильного Base64URL секрета.
- **Маскировка (FakeTLS/Сайт)**: автоматическое создание директории и стартовой страницы для обхода DPI.
- **Готовая ссылка**: в конце установки вы получаете ссылку вида `https://t.me/webproxy?...`.
- **Без привязки к Email**: получение сертификата Let's Encrypt без необходимости вводить личную почту (генерируется автоматически).

## 📋 Требования
- **ОС:** Ubuntu 22.04+ или Debian 12+ (архитектура `x86_64`).
- **Права:** `root` (или пользователь с `sudo`).
- **Домен:** Привязанный к IP-адресу вашего сервера (A-запись).
- Чистый сервер (порты 80 и 443 не должны быть заняты Nginx или Apache).

## 🛠 Установка (Одной командой)

Подключитесь к вашему серверу по SSH и выполните следующую команду:

```bash
sudo bash -c "$(curl -sSL https://raw.githubusercontent.com/IohnMorris/tg_web_proxy_deploy/main/install.sh)"
```

## 🛡 Важно для обхода блокировок (DPI)

Для успешной маскировки трафика от провайдеров (РКН и других систем DPI) ваш сервер должен выглядеть как обычный сайт. 
Во время установки скрипт создает простую заглушку в папке `/srv/tproxy-site`.

**После установки обязательно замените заглушку на полноценный сайт:**
1. Найдите любой бесплатный HTML-шаблон в интернете (или сгенерируйте лендинг через ИИ).
2. Загрузите файлы сайта в директорию `/srv/tproxy-site/` на вашем сервере (например, через SFTP).
3. Убедитесь, что главный файл называется `index.html`.

## ⚙️ Управление сервисами

Если вам нужно проверить статус прокси или перезапустить его, используйте стандартные команды `systemctl`:

**Проверить статус:**
```bash
sudo systemctl status tproxy-server caddy
```

**Перезапустить прокси:**

```bash
sudo systemctl restart tproxy-server
```

**Посмотреть логи (если что-то пошло не так):**

```bash
sudo journalctl -u tproxy-server -n 50 --no-pager
```
```bash
sudo journalctl -u caddy -n 50 --no-pager
```
